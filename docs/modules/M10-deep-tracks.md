# M10 — Треки углубления

**Статус:** `not_started`  
**Зависимости:** M09

## Цель

Выбрать направление «взросления» ConGroo под твой интерес.

## Треки

### A. Virtio-blk
Блочное устройство в QEMU, чтение данных не только из initrd.

### B. Framebuffer UI
Минимальный вывод на FB; не нарушать правило «сначала польза», UI — надстройка.

### C. UDP echo
Учебный сетевой путь: найти кадр, дойти до UDP, ответить. Очень тернисто.

### D. Hardening
W^X, SMEP/SMAP, жёсткие user ptr checks, ASLR-light (опционально).

### E. aarch64 port
Перенос модели на `qemu-system-aarch64`: что архитектурно обязательно меняется.

### F. SMP intro
Второй vCPU: per-cpu данные, TLB shootdown идея, locks. Только если база очень твёрдая.

## Как сдавать M10

1. Выбери трек → создай `docs/notes/adr-m10-track.md` с выбором и почему.
2. Разбей трек на подсдачи `M10A-01-...` и т.д.
3. Для каждого подэтапа — свои acceptance criteria (согласовать с учителем до кода).

## Критерий выхода трека

Не «закончить ОС», а **закрыть обещанный вертикальный срез** трека end-to-end + понять trade-offs.
