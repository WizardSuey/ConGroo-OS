# M00 — Машина, boot-chain, модель памяти

**Статус:** `not_started`  
**Зависимости:** нет  
**Стек акцент:** концепты; asm/linker пока на уровне идей

## Цель

Построить ментальную модель: как управление доходит до ядра и из каких частей состоит «машина», на которой живёт ConGroo.

## Теория (обязательно)

1. Цепочка: QEMU/firmware → bootloader → kernel entry → `kmain`
2. Зачем нужен bootloader и какой контракт у Multiboot2 (обзор)
3. Privilege rings: ring 0 vs ring 3
4. Стек: рост, кадр, риск overflow
5. Interrupt vs exception vs syscall (пока различия словами)
6. Физический адрес vs виртуальный (концепт)
7. Роль linker script и entry symbol
8. Freestanding C и UB: почему осторожность выше, чем в userspace-приложении

## Углубление

- Почему «BIOS писали на asm» не означает, что тебе нужен весь asm
- Разница fault (можно вернуться) и abort (обычно нет)
- Что такое MMIO идея (регистры устройств в адресном пространстве)
